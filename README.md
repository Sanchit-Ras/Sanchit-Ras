### 🛡️ Women's Safety ML System
**Crime Risk Intelligence Platform**

End-to-end ML forecasting pipeline predicting district-level crime trends across **600+ Indian districts**.

- Leakage-proof sliding-window time-series pipeline → **R² = 0.89** on unseen future data
- Containerized **FastAPI** service with Redis caching
- Geospatial layer (GeoPandas + Folium) rendering a choropleth risk map over **432/594 districts**
- Backend on Render, frontend on Vercel

`XGBoost` `scikit-learn` `FastAPI` `Redis` `Docker` `React`

[**Live Demo →**](https://women-safety-ml-system-jwlh.vercel.app/) · [**Code →**](https://github.com/Sanchit-Ras/women-safety-ml-system)

### 🛒 Cheaply
**Grocery Price Comparison Platform**

Full-stack platform that normalizes grocery prices to a per-kg / per-litre basis for fair ranking across brands and pack sizes.

- **Spring Boot 3 (Java 21)** REST API + Python scraping service + React/TS frontend
- Repeat-search latency: **~45s → under 1s** via Redis caching
- Per-store failure isolation — one broken retailer returns partial results, not a 500
- **118 automated tests** running in GitHub Actions CI

`Java 21` `Spring Boot` `PostgreSQL` `Redis` `Docker Compose` `JWT`

[**Code →**](https://github.com/Sanchit-Ras/Cheaply)
